# Vale of Tears

Ever wonder what happens to great poems when you run them through vale
and auto-accept the first suggestion?

- [The Jabberwocky](https://github.com/bocere/vale-of-tears/blob/main/Jabberwocky.md?plain=1)
- [To a Mouse](https://github.com/bocere/vale-of-tears/blob/main/To-A-Mouse.md?plain=1)
- [The Quangle Wangle's Hat](https://github.com/bocere/vale-of-tears/blob/main/The-Quangle-Wangles-Hat.md?plain=1)

For more amusment, try `valeoftears` to mangle a poem. Put the original in `originals/`
and then run `mangleometer` to measure the damage.
